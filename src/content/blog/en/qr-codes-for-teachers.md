A QR code in a classroom is a shortcut, not a feature. It saves you from reading
a URL out loud twenty-eight times while a room of teenagers types it wrong.

That is the whole value. It should cost you nothing, and it should still work
long after you have forgotten you made it.

## Uses that hold up

**Worksheet answer keys.** Put the code at the bottom of the sheet. Students
attempt the work first, then mark their own. It removes a photocopying job and a
queue at your desk.

**Reading and reference links.** An article, a video, a dataset. Printed on the
task sheet rather than dictated, so nobody arrives at the wrong page.

**Lab safety instructions.** A code on the bench or on the equipment itself,
pointing at the procedure for that station. Useful because it is attached to the
thing rather than filed away somewhere.

**Homework submission.** A form link on the sheet. Students submit from the
phone in their hand instead of remembering a URL at 10pm.

**Self-guided displays.** Corridor exhibitions, science fairs, open evenings. A
code beside each piece of work leading to a recording of the student explaining
it. Most goodwill for the least effort.

**The WiFi on the wall.** A [WiFi QR code](/wifi-qr-code) encodes the network
name and password directly in the pattern. A supply teacher or visitor scans it
and connects. No password read aloud, none written on the board.

## Static codes and the budget reality

Teachers buy their own laminating pouches. Plan accordingly.

Most QR code services sell you a *dynamic* code: the printed pattern points at
their server, which redirects to your real destination. The pitch is that you
can change the destination later. The cost is that it only works while their
account is paid. Miss a renewal and every laminated poster in your room dies at
once.

A **static** code has the destination baked into the pattern itself. There is no
account, no renewal, no company in the middle. It works for as long as the
destination works — and if the code contains plain text or WiFi credentials
rather than a link, it works indefinitely. More detail in
[Do QR codes expire?](/blog/do-qr-codes-expire).

The trade-off, stated plainly: a static code cannot be re-pointed. If the URL
changes, you reprint that sheet. The way around it is to point at an address you
control and intend to keep, then change what sits at that address rather than
the code.

For a poster you laminate once and use for five years, that is the right trade.

## Printing on the school photocopier

The copier is the real constraint, not the code. Toner spreads on cheap paper,
which thickens the black modules and closes up the white gaps between them.
Contrast drifts. Nobody has replaced the drum since 2019.

| Setting | What to use |
| --- | --- |
| Error correction | M normally, Q for the school copier or coloured paper |
| Minimum size | 2.5 cm square; 3 cm if the sheet gets folded or handled |
| Colour | Pure black on plain white. No greys, no tinted paper |
| Quiet zone | Blank margin four modules wide on all four sides |
| Proof | Scan the photocopy, not the screen |

That last row is the one people skip. A code that scans perfectly from your
laptop can fail on paper, because the screen is backlit and the paper is not.
Run one copy, scan it, then run the other twenty-nine.

Never copy a copy. Each generation loses contrast, and the second-generation
sheet is usually the one that fails. Keep the original file and reprint from it.

[QR code minimum size for printing](/blog/qr-code-minimum-size-printing).

## Not every student has a phone

This part matters more than the rest of the post.

Some students have no smartphone. Some have one with no data allowance left by
the middle of the month. Some share a family device that is not with them during
the school day. Some have a cracked camera or an older Android with no scanner
built into the camera app. And plenty of schools ban phones outright, which
makes a QR code on a worksheet a rule you are quietly asking students to break.

So the rule is simple: **a QR code must never be the only route to required
material.**

- Print the web address in text next to the code.
- Keep paper copies of anything a student needs to complete the work.
- Put the same link wherever your class already lives online.

One technical split is worth knowing. Plain text and WiFi codes contain the data
itself, so they work with no connection at all. A link code contains only an
address, so a phone with no signal shows the URL and stops there. If a lab sits
in a basement with no reception, encode the safety steps as text rather than as
a link to them.

Use the QR code to make the easy path easier. Never to make the only path
conditional on owning a device.

## Teach them to read the destination first

Every modern phone shows the address before opening it. Most students tap
straight through without looking.

Worth ten seconds of teaching: scan, read the address, then decide. A code on a
worksheet from you is not the same as a code stuck to a lamppost outside the
gate, and the difference is visible in the preview.

Printing the address in text beside the code supports the habit. It also lets
anyone spot a sticker placed over your code — which happens, and is covered in
[Are QR codes safe?](/blog/are-qr-codes-safe).

## Small things that save you a reprint

**Laminate matte, not gloss.** Gloss reflects the ceiling lights straight back
into the camera and wipes out whole regions of the pattern. Matte pouches cost
the same.

**Place it where a phone can be held steady.** Eye level, on a vertical surface,
with room to stand. Not above a doorway, not behind a desk, not flat on a bench
under a strip light.

**Number multiple codes on the same sheet.** Two unlabelled codes make students
guess, and half of them guess wrong. Write `1. Answer key` and `2. Extension
task` next to each.

**Leave the white margin.** Cropping the quiet zone is the single most common
reason a correctly sized code refuses to scan.

## Before you print thirty copies

1. Generate a static code, error correction M or Q.
2. Set it at 2.5 cm or larger, black on white, with its margin intact.
3. Print one copy on the actual machine, on the actual paper.
4. Scan that copy with an old phone, not your newest one.
5. Check the address in text beside it is correct.
6. Confirm a student without a phone can still do the work.
